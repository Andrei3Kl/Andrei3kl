# 💫 About Me:
<br>Hi, I'm Andrei, also known as Andrei3k. I'm interested in reverse engineering, x86-64 binary analysis, and low-level systems programming.<br><br>I enjoy looking past the usual layers of software to understand what is actually happening underneath: machine instructions, registers, calling conventions, memory layouts, and program behavior at runtime.<br><br>I enjoy taking apart compiled software to understand its internal logic, especially when there is little or no documentation available. I create tools that help automate repetitive analysis, process binary data quickly, and turn difficult control-flow information into clear, interactive visualizations.
